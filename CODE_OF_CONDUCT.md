# Code of Conduct

This project follows the [CNCF Code of Conduct][cncf], the same code of conduct
as OpenTofu.

Report violations privately to a maintainer listed in
[CODEOWNERS](.github/CODEOWNERS). Please do not report them in a public issue.

[cncf]: https://github.com/cncf/foundation/blob/main/code-of-conduct.md
